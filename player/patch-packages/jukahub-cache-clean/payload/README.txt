JukaHub Cache Cleaner
=====================

Installed by the Patch package manager (MISC > Patch).

What it does
------------
Removes JukaHub-owned temporary files (*.part, *.tmp) from the cache
directory. It never deletes user data, saves, ROMs, themes or configs.

Usage
-----
Run from a terminal:
    /JukaHub/tools/jukahub-cache-clean.sh /path/to/cache

Remove
------
Use Patch > Packages > Remove to uninstall this package; the files it
installed are removed automatically and the original state is restored.
