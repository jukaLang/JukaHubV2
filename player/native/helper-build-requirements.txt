# Python packages for player/native/build-helpers.sh (and the CMake the Box64
# pack builds with), exactly as the release installs them into its Ubuntu 20.04
# arm64 build root (Python 3.8, aarch64) in .github/scripts/build-root.sh:
#
#   python3 -m pip install --no-cache-dir --only-binary=:all: --require-hashes \
#       -r helper-build-requirements.txt
#
# Every version is exact, every wheel is hashed (TEST-15), and only published
# wheels are accepted, so nothing is compiled from source and no setup.py
# runs. The hashes are the sha256 digests PyPI publishes for the aarch64 /
# Python 3.8 wheels pip selects in this root; change a version, a wheel or a
# Python version and all four hashes must be looked up again.
# setuptools (pkg_resources, which grpc_tools needs on Python 3.8) and ninja
# come from Ubuntu's python3-setuptools and ninja-build packages.

# CMake 3.24 or newer for chiaki-ng; 4.x refuses its submodules' old
# cmake_minimum_required. manylinux_2_17_aarch64 wheel.
cmake==3.31.6 --hash=sha256:42d9883b8958da285d53d5f69d40d9650c2d1bcf922d82b3ebdceb2b3a7d4521
