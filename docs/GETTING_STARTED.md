# Getting started with JukaHub

This is a short guide to the first few minutes. You can return to it from
**Settings → About → Quick start**, even when you are offline.

## First start

The welcome tour shows the main buttons and lets you choose a name, colours and
a Home layout. Its **Get set up** page offers Wi-Fi, media tools and other
optional features. You can skip any step and replay the tour later from
**Settings → General → Replay tour**.

## Find your way around

Use the D-pad to move, **A** to open and **B** to go back. On a keyboard, use the
arrow keys, **Enter** and **Esc**. The hints along the bottom of each screen
show what its buttons do. Press **Start** (or **F10** on a keyboard) to open the
menu from most screens; **Select** opens Quick Settings. A mouse or touch screen
can open the same tiles and buttons.

Home has tiles for Games, Media, Files, Settings and the other parts of JukaHub.
The **Start** menu also lists screens, games, tools and device controls. If you
cannot find something, press **Y** on Home to search for it.

## Play a game

Open **Games Library** from the Games tile or **Start → Games → Games Library**.
Choose a console, then a game. On a handheld, the library reads games from the
card's `Roms` folders. You can also send a game from your phone: open the
**Phone Companion** pairing card, scan its code on a phone on the same network,
and use **Send to the handheld**. JukaHub places recognised games on the right
shelf. The library can still show a game when its cover is missing.

## Make it yours

Open **Settings** from Home to change Wi-Fi, controls, display and appearance.
**Settings → Theme & look → Home layout** changes the layout you chose in the
tour. **L2** on Home opens Edit Home so you can move or add tiles; press **L2**
again when you are done.

## More help

**Settings → About → Controls** has the full button guide. On a keyboard,
**F1** opens the controls for the screen you are using. The **?** row in Quick
Settings does the same with a controller. You can always return here from
**Settings → About → Quick start**.
