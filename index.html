Quick start

How it works

  1. On desktop: Drag elements from the left sidebar to the canvas
    • Double-click elements to edit
    • Right-click + drag to resize images
    • Drag elements to reposition
  2. On mobile: Use the + button to add elements to the canvas
    • Tap elements to select and edit properties
    • Use drag handles to reposition elements
  3. Select elements to edit properties in the right sidebar
  4. Use the "Export" dropdown to download as JSON or XML
  5. Combine with the JukaHub template from GitHub releases

Keyboard shortcuts

  • Ctrl+Z / Ctrl+Shift+Z — Undo / Redo
  • Delete — Remove selected element
  • Ctrl+D — Duplicate selected element
  • Ctrl+C / Ctrl+V — Copy and paste an element (paste it into another scene too)
  • Ctrl+S — Export JSON
  • Ctrl+P or Ctrl+Shift+P — Toggle Preview Mode; Esc — Exit Preview
  • Ctrl+Shift+K — Check the design for problems
  • Arrow keys — Nudge the selected element (Shift moves 10 px)
  • Right-click elements for a context menu
