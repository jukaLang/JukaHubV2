## Overview

JukaHub is a config-driven GUI framework for handheld gaming devices. Design your interface visually in a browser, then run it on your device. No recompilation needed — just edit `jukaconfig.json`.

### Two Components

1. **Web Builder** — Drag-and-drop interface at [generate.jukalang.com](https://generate.jukalang.com) to generate `jukaconfig.json`
2. **Player** — Go/SDL2 runtime that executes the config and renders the UI

## Quick Start

### For End Users

1. Download the latest `JukaHub` binary for your device
2. Place `jukaconfig.json` in the same folder
3. Run `./JukaHub` (Linux/macOS) or `JukaHub.exe` (Windows)

### For Developers

```bash
# Clone the repo
git clone https://github.com/jukaLang/JukaHubV2.git
cd JukaHubV2/player

# Install SDL2 dependencies (Ubuntu/Debian)
sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev

# Build
go build -o JukaHub.exe .

# Run
./JukaHub
```

### Building for ARM64 Handhelds

Cross-compile from your PC:

```bash
# Set ARM64 environment
export GOOS=linux
export GOARCH=arm64
export CGO_ENABLED=1
export CC=aarch64-linux-gnu-gcc

# Build
go build -o JukaHub .
```

## Configuration

JukaHub uses two JSON files:

### `jukaconfig.json` — Design Config
Contains static UI layout, scenes, colors, fonts, and element positions. This file is generated by the web builder and should not be edited manually unless you know the structure.

### `jukauser.json` — User Data
Created automatically. Stores mutable settings:
- Theme overrides (button/label/input colors)
- Fullscreen preference
- Weather unit (°C/°F)
- Username
- Playback resolution
- File explorer root
- Custom variables

### Variables Reference

| Variable | Type | Description |
|----------|------|-------------|
| `buttonColor` | `#rrggbb` | Button background color |
| `labelColor` | `#rrggbb` | Text color for labels |
| `inputColor` | `#rrggbb` | Input field background |
| `fullscreen` | `bool` | Launch in fullscreen |
| `screenWidth` | `int` | Logical screen width |
| `screenHeight` | `int` | Logical screen height |
| `weatherEnabled` | `bool` | Enable weather fetch |
| `weatherUnit` | `"C"` / `"F"` | Temperature unit |
| `tspUsername` | `string` | Username for greetings |
| `playbackResolution` | `string` | Max video height (e.g. `"720"`) |
| `fileExplorerRoot` | `string` | Root directory for file browser |
| `tools_path` | `string` | Path to yt-dlp/ffplay binaries |

## Features

### 🎬 Media Playback
- **YouTube Search** — Search and play videos directly
- **Trending** — Browse trending YouTube content
- **Custom Link** — Paste any direct video URL (YouTube, Twitter/X, TikTok, Instagram, etc.)
- **IP Stream** — RTSP/HTTP live streams
- **Live TV / IPTV** — M3U playlist support
- **Podcasts** — RSS feed aggregator with curated and custom feeds
- **YouTube Shorts** — Dedicated Shorts browsing and auto-play
- **MPV / ffplay backend** — Configurable audio backend (ffplay or MPV)

### 📁 File Management
- **File Explorer** — Browse local files with media detection
- **Unzip** — Extract `.zip` archives in-place
- **Image Viewer** — Full-screen image viewing with zoom/pan
- **Recently Played** — Auto-tracked with visual indicators

### 🛠️ Tools
- **Network Speed Meter** — Download speed test with latency
- **Read/Write Benchmark** — Sequential and random I/O performance testing
- **Hardware Monitor** — System info with auto-refresh and log export
- **Cron / Task Scheduler** — Manage cron, systemd, init.d, rc.local, supervisor, Windows services
- **Startup Items** — View boot-time applications
- **Terminal** — Execute shell commands
- **Weather** — IP geolocation with °C/°F toggle
- **Disk Space Pie Chart** — Auto-refresh graphical visualization

### 🎮 Creative & Social
- **Canvas Sandbox** — HTML5 Canvas API playground with JS-like editor
- **Unit Converter** — Category-based conversion (length, weight, temperature, volume, speed, time, data, area)
- **Chat System** — Local persistent chat (JukaLand multiplayer ready)
- **Favorites** — Tabbed system (Videos, Recent, Files, IPTV) with play-on-click
- **Theme Presets** — Light / Dark / OLED mode switching
- **Plugin System** — Custom modules and extensions

### 🎯 UX
- **On-Screen Keyboard** — Virtual keyboard for text input
- **Smooth Transitions** — Fade scene transitions and button feedback
- **Toast Notifications** — Slide-in status messages

```
JukaHubV2/
├── index.html           # Web-based GUI builder
├── player/
│   ├── main.go          # Main application entry
│   ├── extras.go        # Status bar, config persistence
│   ├── features.go      # File explorer, dynamic lists
│   ├── morefeatures.go  # IPTV, podcasts, tickers, weather
│   ├── hardware.go      # System info, benchmarks
│   ├── net.go           # Network speed tests

│   ├── jukaconfig.json  # Design config (generated)

├── required/            # yt-dlp, ffplay binaries
└── tv/                  # IPTV .m3u playlists (user-created)
```

## Troubleshooting

### Videos won't play
1. Check that `yt-dlp` and `ffplay` exist in the `required/` folder or system PATH
2. Ensure network connectivity for YouTube/streaming
3. Check terminal/log output for specific error messages

### Black screen on launch
- Verify `jukaconfig.json` is valid JSON
- Check that font files (`DejaVuSans.ttf`, `Inter-Regular.ttf`) are present
- Try deleting `jukauser.json` to reset settings

### Performance issues
- Lower `PlaybackResolution` in Settings (try `"480"` or `"720"`)
- Disable weather/ticker updates in Settings
- Close other running applications

### Touch/controls not responding
- Ensure your device's SDL2 input driver is properly configured
- Try connecting a USB keyboard for navigation
- Force exit with Select + Start

### yt-dlp/ffplay not found
- Place binaries in the `required/` folder
- Or set `tools_path` in Settings to the directory containing them
- On Linux handhelds, install via package manager if available
